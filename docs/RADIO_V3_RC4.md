# Radio 1.1.0-rc4 动画版

2026-10-30。保留十套 UI，在七套像素／场景风格上增加轻量动效。未访问、复位或烧录 COM6。

## 七套动画

- 像素主播：上下轻浮，音符缓慢上升。
- 猫咪 DJ：小幅律动，音符上升。
- 太空电波：宇航员漂浮，星光明暗变化。
- 海边落日：海面波光横向移动和闪动。
- 雨夜便利店：两侧雨滴下落，地面反光轻变。
- 掌机音乐盒：机器人小幅跳动，屏幕装饰条和音符变化。
- 像素花园：飘叶和萤光。

其中装饰条、星光等属于氛围动画，不是测量值。声波极简及点阵电波原有 PCM 电平显示继续保留；编辑风保持静态。艺术素材仍是之前确认的 AI 图片，没有重新生成角色。

## 行为与开销

动画只在实际 PLAYING 且主屏可见时推进；暂停、连接、缓冲和错误状态停止并回到静止位置。像素主播的暂停表情不再在连接阶段冒充播放表情。

列表、设置、配网和控制中心打开时冻结本地动画时钟。返回后接着运行，不累积后台时间后突然补跳。关闭或切肤时复用原有页面生命周期，无独立动画任务或计时器。

复用现有 120ms UI tick，目标上限约 8.3 次更新／秒。每套仅增加两个透明 LVGL 容器，动画裁切在 x=76..283、y=98..215 的插画区域，不移动标题和操作区；不加入序列帧、大画布或 GIF 解码器，不改变平台绘制缓冲、SPI 参数、I2S 时序和播放器网络策略。
