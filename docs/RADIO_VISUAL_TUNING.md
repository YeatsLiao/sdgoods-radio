后续用户要求已替换为纸感与三款 AI 唱片，当前源码共 13 套，尚未编译；见 [接入记录](RADIO_REDRAW_INTEGRATION.md)。下文保留为 RC7 历史记录。

方案与实现范围：顶部时间／LIVE 上移、角色区放大、广播标签替换大字编辑风、像素唱片追加为第 11 套。已随 1.1.0-rc7 编译、主机回归、打包并烧录；构建身份见 [RADIO_V3_RC7.md](RADIO_V3_RC7.md)。

## 已改的共用布局

- 时间顶部 y：54 → 28；LIVE／状态顶部 y：80 → 52，红点同步上移。
- 保留原有九套非编辑风主题与角色，广播标签替换编辑风，像素唱片追加为第 11 套。原七套角色／场景画布从 208×116 调整为 240×140；可见内容高度从 104px 到 128px，约放大 23%，按比例重新采样，不裁主体。
- 角色与唱片的动画父区域为 (56,74)，尺寸 248×148；原素材仍保留四周 4px 容器边距和至少 6px 透明边距。这些样式的台名 y=222、频率 y=252，播放控件与列表按钮不下移；广播标签的文字放在标签内部。
- 动效坐标随画布尺寸缩放，保留原有位移幅度、120ms 更新节奏和“暂停仍动、隐藏冻结”。外观页预览保持原中心，透明边距避开标题和风格名称。
- 素材继续使用原图集、最近邻采样和 16 色索引格式；转换器直接读取头文件里的画布尺寸，避免数组与布局定义不一致。
- 用户已确认 C 替换原“大字编辑风”、D 作为新增第 11 套。广播标签保留 `editorial` ID 和第 1 个位置，旧设置无需迁移；新增 `vinyl-club` 放在第 11 个位置，不改变其余旧 ID 的顺序。主屏循环、设置计数及预览统一使用 11 套注册表。

## 用户选定的构图方向

概念图：[C/D 平面像素化对比](design/radio-v3/proposals/cd-flat-pixel.png)。这是生图方案，不是当前 LVGL 渲染或设备截图；文字形状、按钮细节和细微光影不作为精确实现规范。

### C — Orange Label

已在源码中替换：奶油底、珊瑚色广播标签、奶油色标签文字，控件沿用墨色。32px 单行台名与频率分成两层，取消重复 FM、重复全称和满屏巨字；长台名在固定视口内滚动。

标签区域为 (60,82)，尺寸 240×170；使用纯色矩形、细分隔线和阶梯像素角，不使用渐变、投影或整屏图片。台名和频率保持动态：已知 FM 显示 `FM 105.4`，网络频道显示 `CH 03`，无编号时显示“网络电台”，不捏造 FM。外观页也使用同一绘制逻辑。

### D — Vinyl Club

保留唱片与唱臂的主视觉，但转成原有低色数像素插画：粗像素环、平涂中心标签、简化唱臂，不做写实黑胶纹理或金属反光。

已作为 `vinyl-club` 追加到源码注册表：原生绘制 4px 方块，按行合并同色块组成唱片、唱针及固定唱臂；旋转标记由现有 120ms 时钟驱动，一圈约 7.2 秒。暂停、缓冲、连接失败时继续转，隐藏主屏时冻结。外观页使用静态预览。没有新增位图数组、GIF、帧缓存或定时器；台名、频率与播放状态仍用原有组件。
