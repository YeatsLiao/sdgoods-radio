# 纸感与三款唱片接入（2026-10-30，仅源码）

本次只修改代码与素材源码，没有编译、运行主机 C 回归、打包或烧录，版本号不变。RC7 发布记录是历史记录。

- 第 1 套 `paper-radio` 纸感收音机替换橙色广播标签。暖纸色、32px 动态台名、独立频率、AI 风景与代码刻度盘。88–108MHz 有效频率驱动指针，无可靠频率时隐藏指针。
- 第 11 套 `vinyl-pixel` 薄荷像素唱机（B）替换原来的粗像素黑胶。
- 第 12 套 `vinyl-pop` 蓝橙唱片（A）、第 13 套 `vinyl-night` 紫夜唱片（C）作为新风格加入。
- 其余 9 套保持位置和 ID。主屏左右滑、外观预览、应用保存、计数统一使用 13 套注册表。旧 `editorial`、`vinyl-club` 在查找与设置读写时分别映射到纸感、薄荷像素。

原图及提示词在 [设计目录](design/radio-v3/proposals/vinyl-redraw-20261030/README.md)。复用确认的 AI 图片，台名、频率、时钟、状态及按钮保持 LVGL 动态对象，没有截进位图。唱片的音乐符号使用原有动画时钟，暂停继续、隐藏冻结，不影响播放意图。

`tools/prepare_radio_redraw.py` 输出 `main/apps/ui_radio_redraw_assets.c/.h` 和 `main/assets/radio/redraw/manifest.json`，记录图源 SHA-256、提取区域、尺寸、透明边界与字节数。纸感场景排除示例指针和数字，三张唱片没有地标。唱片使用 240×140、64 色索引素材，完整缩放并留透明边距，四张素材共 107,800 字节。

纸感卡片溢出修正：原风景图与外卡片同宽，且父对象只画圆角背景、未裁切子对象，导致图片方角露出。图像改为 276×28，尺寸从 UI 头文件读取；放入距边缘 6px 的内圆角视窗。卡片及内视窗均开启子对象圆角裁切，卡片边框在子对象之后绘制。没有改变频率刻度、指针或播放布局，没有修改平台显示缓冲和功耗策略。本次仅静态验证，尚未编译或烧录。

不再需要旧的 48px 大标题，350 字高精度子集调整为实际使用的 32px，字形位图降至 95,598 字节，用来抵消新图片的主要开销。实际固件大小仍须下次编译后核验。
