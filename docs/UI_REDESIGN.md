# 城市电台 · UI / 交互重构设计（v2）

> 目标：把「圆屏 FM 表盘」从**功能演示**升级为**可长期放在桌面上的产品**。
> 关键词：单色编辑风、点阵大字、双主题、少而准的信息、拖拽调台。
>
> 适用固件：本仓根目录工程（ESP32-S3 + 360×360 圆屏 + ESP-IDF 5.5 + LVGL 8.3）

---

## 1. 现状审计：为什么「效果很差劲」

| 维度 | 旧实现 | 用户感受 |
| --- | --- | --- |
| 视觉 | 单一深蓝背景 + 天蓝弧 + 琥珀大字 + 绿电平条，四种高饱和色互相打架 | 像 2010 年的车机，没有品牌感 |
| 主视觉 | 中央是 `cn_font_16` 的 16px 频率字，信息量最大的位置却最小 | 远看只有一个空心圆 |
| 内容 | 大量网络台没有 FM 频率 → 常年显示 `--.- MHz` | 主视觉长期是空的，产品像坏的 |
| 交互 | 上滑 = 下一台，与平台「上滑 = 回主页」冲突；全屏轻点即播放/暂停 | 误触、手势打架 |
| 结构 | 设置是一个 5 个等宽按钮的浮层，层级扁平 | 找不到东西，也无处可扩展 |
| 文案 | 走 `SDG_T()`，出厂语言是英文 | 中文产品开机显示 `Connecting…` |
| 内容源 | 只按国家取台，无「城市」概念；含 OGG/HLS 不可播流 | 一半的台播放失败后自动跳台 |

## 2. 设计定位

参考「城市电台」产品页与 leo-radio 的组织方式，形成三条硬规则：

1. **单色 + 一个点缀色**：版面只有纸色/墨色，红色只用于「正在直播」的进度与端点。
2. **一个英雄元素**：5×7 点阵大数字（`101.7`），是唯一允许「大」的元素，其余全部克制。
3. **信息分层只有三级**：主视觉 → 台名 → 元信息；任何第四级信息都必须收进列表页。

## 3. 设计系统

### 3.1 色板（双主题，运行时可切）

| Token | 纸张 PAPER | 夜色 NIGHT | 用途 |
| --- | --- | --- | --- |
| `bg` | `#F4F1E8` | `#0C0C0D` | 全屏底色 |
| `ink` | `#14140F` | `#F4F1E9` | 主文字、点阵、电平条 |
| `muted` | `#8A877C` | `#8B8B85` | 次级文字、未激活弧 |
| `hair` | `#D8D3C4` | `#2A2A28` | 1px 分隔线、轨道弧 |
| `accent` | `#D8362A` | `#FF4436` | 进度弧、端点、直播状态点 |
| `card` | `#EAE5D8` | `#17171A` | 列表行按下态、胶囊底 |
| `on_accent` | `#FFFDF6` | `#0C0C0D` | 反白文字 |

默认主题 = 纸张（更接近「城市电台」产品调性），用户可在设置中切换并持久化。

### 3.2 字体层级

| 层级 | 字体 | 用途 |
| --- | --- | --- |
| 英雄 | 自绘 5×7 点阵 | 频率 `101.7` / 频道号 `07` |
| 标题 | `net_font_20`（2bpp，3817 字） | 台名、列表主行、页面标题 |
| 正文 | `cn_font_16`（4bpp，1170 字） | 按钮、设置行主字 |
| 注释 | `cn_font_14`（4bpp，1170 字） | 元信息、页头、右侧值 |

### 3.2.1 为什么需要两套中文字体

界面文案是**编译期确定**的，`cn_font_*` 只需收「源码里出现过的字」；但**电台台名来自网络**，
编译期无法穷举 —— 早期实现里「杭州城市资**讯**广播」的「讯」不在子集内，`rk_text_safe()`
就把它换成了 `?`。

于是分出一张专供运行时字符串的 `net_font_20`：

* 字符集 = `GB2312 一级汉字（0xB0A1–0xD7F9，3755 字）` ∪ 源码字符集；
* 20px / **2bpp**（台名在 20px 下 2bpp 已足够，体积只有 4bpp 的一半）；
* `.fallback = &cn_font_16`（跨字号 fallback 合法）：一级字库外的生僻字退到 16px 子集；
* 二级字库（0xD8 起，又 3000 多字）不收 —— 体积翻倍而命中率极低。

体积账：app 分区 3MB，`cn_font_20 + si_yuan_black_icon_20` 共约 300KB，换成
`net_font_20` 后固件 2,920,784 B、剩余 7%。重新生成：

```bash
python tools/gen_fonts.py --sizes 14,16 --net-size 20 --net-bpp 2 \
    --bin "node_modules\.bin\lv_font_conv.cmd"
```

> 规则：**凡是来自网络的字符串（台名），排版时一律用 `RK_FONT_TITLE`（= `net_font_20`），
> 并先过 `rk_text_safe()`**。`rk_text_safe()` 逐码点用 `lv_font_get_glyph_dsc()`
> （该 API 会查 fallback）校验，缺字形替换为 `?` 而不是方框。

### 3.3 圆屏安全区

圆屏半径 180（中心 180,180）。**顶部 50px 是平台控制中心手势层，任何文字/控件都不得落在 y<50。**

| y 区间 | 可用横向 | 用法 |
| --- | --- | --- |
| 64–90 | 44–316 | 页头（品牌 / 时钟 / 关闭） |
| 96–164 | 20–340 | 点阵英雄 |
| 166–272 | 50–310 | 台名 / 元信息 / 电平 / 胶囊 |
| 268–324 | 73–287 | 底部 dock |

## 4. 信息架构

```
主屏（唯一常驻）
├─ 点按空白        播放 / 暂停
├─ 横向拖拽        连续调台（松手起播）
├─ 长按空白        设置
├─ 点「电台列表」  列表页
└─ 顶部下滑        控制中心（平台）
列表页
├─ 点行            播放并返回主屏
└─ 页头「设置」    设置页
设置页
├─ WiFi 配网       扫描 → 输密码 → 连接
├─ 城市            选择器（自动定位 + 15 个城市）
├─ 主题            选择器（纸张 / 夜色）
├─ 定时休眠        选择器（关 / 15 / 30 / 45 / 60 / 90 分钟）
└─ 刷新电台        重新拉目录
```

设置页固定 5 行、**一屏全可见**（40px 紧凑行 × 5 = 200px，见 §5.1），不放「返回」行
（页头 ✕ 已足够）。

主屏不再有独立「设置」按钮：设置只从列表页进入 + 长按兜底，保证主屏只有一个可点目标（列表）。

## 5. 主屏布局（像素）

| 元素 | 坐标 | 说明 |
| --- | --- | --- |
| 品牌字「城市电台」 | x=58, y=64–80, 14px | 可点 → 设置（隐藏入口） |
| WiFi 点 | 8×8 圆点，x=272, y=69 | 已连=accent，未连=muted |
| 时钟 `8:07` | 右对齐 x=302, y=64–80, 14px muted | 未对时显示 `--:--` |
| 分隔线 | x=58–302, y=90, 1px hair | |
| 表盘环 | 圆心 (180,180)，r=168，60° 底部缺口（120°→420°） | 轨道 3px hair；进度 4px accent；端点 11px 圆 |
| 点阵英雄 | 框 x=30–330, y=98–164 | dot=6, gap=4, 5×7，最多 6 字 |
| 台名 | 居中，y=166，宽 300，20px | 单行省略 |
| 元信息 | 居中，y=196，14px muted | `城市 · 128k · 第 3/26 台` |
| 电平条 | 18 根，w=5 gap=5，基线 y=234，高 ≤18 | 仅播放中显示 |
| 胶囊「电台列表」 | 居中，y=240，高 24，圆角 12 | 显示台数 |
| dock 上一台 | 40×40 圆，x=96, y=276 | 图标 PREV |
| dock 播放/暂停 | 56×56 圆，x=152, y=268 | 底色 ink，图标 on-accent |
| dock 下一台 | 40×40 圆，x=224, y=276 | 图标 NEXT |

点阵几何：单字宽 `5*dot+4*gap = 46`，字距 `gap*2 = 8`，总宽 `46+(n-1)*54`。
`101.7` → 262px；`07` → 100px。

> 没有 FM 频率的纯网络台，英雄位显示**频道号**（`%02u`，如 `07`）而不是 `CH07`：
> 纯数字在 5×7 点阵里可读性远好于 `C`/`H` 这类字形，也不依赖任何字体。

### 5.1 二级页骨架（圆屏专用）

页头：标题 16px 在 `(58,62)`，右上 ✕ 34×34 在 `(274,58)`，分隔线 `y=90`。
内容区 body 从 `(52,100)` 起，宽 256。

| 页面 | 行高 | 可见行数 | 说明 |
| --- | --- | --- | --- |
| 列表 | 48px | 4 行 + 部分第 5 行 | 台名 20px（`rk_page_row_net`），单行省略 |
| 设置 | 40px | **5 行全可见** | `rk_page_row_compact`，5×40=200 正好塞满 body |
| WiFi | 48px | 4~5 行 | 标题右侧「重扫」，扫到的 SSID 列表，点行进密码页 |
| 选择器 | 48px | 按项数 | 当前项 accent 色 + 左侧竖条 |

> 圆屏上「可以滚动」是**不可见**的：任何必须滚动才能看到的内容都应当作不存在来设计。
> 设置页就是因此从 48px 改成 40px 行高的。

## 6. 交互规格

| 手势 | 触发判定 | 行为 |
| --- | --- | --- |
| 点按主屏空白 | 位移 ≤24px 且松开 | 切换播放/暂停；`RP_ERROR/IDLE` 时重播当前台 |
| 横向拖拽 | 位移 ≥18px 后进入拖拽态 | 每 26px 换一台，**只预览**（点阵/台名/环同步），松手才起播 |
| 点 dock 按钮 | `sdgoods_tap_bind` 位移守卫 | 上一台 / 播放暂停 / 下一台 |
| 长按主屏 | 400ms（LVGL 默认） | 打开设置页；随后补发的 CLICKED 必须被吃掉 |
| 顶部下滑 | 平台外壳 | 控制中心（音量/亮度/电量） |
| 底部上滑 | 平台外壳（底部 110px 带） | 回启动台（dock 区域被遮挡属预期，两侧仍可上滑） |
| 左缘右滑 | — | 不注册，避免与拖拽调台冲突 |

拖拽细节：

* 拖拽中 `s_preview_idx` 独立于 `s_cur_idx`；`PRESS_LOST` 或松手未过阈值时回滚。
* 取模循环，首尾可无缝绕回。
* 一次拖拽最多预览 64 台（目录上限），无额外限流。

## 7. 状态与文案

| 播放器状态 | 点阵 | 环 | 元信息 |
| --- | --- | --- | --- |
| 目录加载中 | `....`（4 个点闪烁） | 隐藏进度 | `正在获取城市电台…` |
| `RP_CONNECTING` | 频率 / 频道号 | accent 弧 | `连接中 · 3/26` |
| `RP_BUFFERING` | 频率 / 频道号 | accent 弧 | `缓冲中 · 3/26` |
| `RP_PLAYING` | 频率 / 频道号 | accent 弧 + 端点 | `城市 · 128k · 3/26` |
| `RP_PAUSED` | 频率 / 频道号 | accent 弧变 muted | `已暂停 · 3/26` |
| `RP_ERROR` | 频率 / 频道号 | muted | `信号中断 · 3/26` |
| 无数据 | `----` | 隐藏 | `请先连接 WiFi` |

换台成功后：台名 `105 → 0` 透明度 + 上移 6px 的 180ms 淡入（只重绘台名小区域，避免整屏 flush）。

## 8. 目录服务（城市）

* 主查询：`/json/stations/search?name=<城市>&order=votes&reverse=true&hidebroken=true&limit=40`
  中文城市名按 UTF-8 百分号编码。
* 补足查询：`?countrycode=<CC>&order=votes&reverse=true&hidebroken=true&limit=40`
  （旧实现的 `s-hidebroken` 参数名错误，服务端忽略，已修正为 `hidebroken`）。
* 合并后：按 URL 去重；过滤 `codec` 为 OGG/OPUS/FLAC/HLS 及 URL 含 `.m3u8/.pls` 的不可播条目；
  截断到 `RADIO_CATALOG_MAX`(64)。
* 自动定位：`ip-api.com`（`lang=zh-CN`，取 `countryCode` + 城市名）→ 失败退 `ipwho.is`。
* 全部失败：内置 3 台精选（Radio Paradise / SomaFM），并让 UI 显示「离线精选」。

设计取舍：**主题切换与目录刷新一律重建屏幕**（`lv_scr_load` 新屏 + 删除旧屏），
播放器不动，播放不中断；平台 100ms 看门狗会把控制中心手势重新绑到新屏。

## 10. 验收标准

1. 开机 3 秒内主屏可见，且**没有任何控件落在 y<50**。
2. 无频率的台显示频道号（`07`）而不是 `--.-`，主视觉不空。
3. 点阵 `101.7` 在 1 米外可读；台名 20px 无方框。
4. 横向拖拽 3 屏内可跨 ≥10 台，松手 1 秒内出声。
5. 顶部下滑进控制中心、底部上滑回启动台均正常，且与拖拽调台不冲突。
6. 纸张/夜色切换后重启保持；城市切换后列表首屏即该城市电台。
7. `idf.py build` 无 warning 级新增告警；固件 < 3MB app 分区。

## 11. 真机验收通道（串口诊断键）

本机没有键鼠，而**截屏一次只能拍当前那一屏** —— 列表 / 设置 / WiFi / 夜色主题这些
二级状态无法远程验收。`ui_radio.c` 覆盖了平台的弱符号 `sdgoods_console_ext_cmd()`，
把字母映射成一次**合成触摸**（`sdgoods_tap_synth()`，与真实点按同一条路径），
全部经 `lv_async_call` 排回 UI 上下文，避免跨任务操作 LVGL。

| 键 | 行为 |
| --- | --- |
| `l` | 点「电台列表」胶囊（x=180, y=252）→ 列表页 |
| `k` | 点左上品牌字（x=106, y=70）→ 设置页 |
| `w` | 点设置页首行「WiFi 配网」（x=180, y=124） |
| `n` | 纸张 / 夜色互换（等价设置页里那一路，会重建屏幕） |
| `x` | 关掉所有页面回主屏（连续截屏收尾用） |
| `1`–`9` | 直接播第 N 台（目录下标从 0 起） |

配合截屏工具使用（`--pre` 支持逗号分隔的**按键序列**）：

```powershell
# 一级页
python tools/screenshot_recv.py -p COM6 -t --pre "l" --pre-boot 12 --wait 4 -o docs/shots/page_list.jpg
# 二级页：x 回主屏 → k 开设置 → w 点首行进 WiFi
python tools/screenshot_recv.py -p COM6 -t --pre "x,k,w" --pre-boot 12 --pre-gap 3 --wait 5 -o docs/shots/page_wifi.jpg
```

⚠️ 时序：**打开串口会拉一下 DTR 导致设备复位**，复位瞬间发的键会丢。
所以先 `--pre-boot 12`（等启动完）再发键，键间留 `--pre-gap 3`（等页面建好）。
