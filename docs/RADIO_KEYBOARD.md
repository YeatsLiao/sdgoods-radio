# 中央分页大键盘（仅源码，2026-10-30）

针对圆屏边缘 q、a、0 等键难点的问题，取消每行 9–10 键的贴边布局。字符区固定在 x=60..299、y=168..277，5 列 × 3 行，每键 44×34px；底部四个操作键为 42×30px，整体居中。按键矩形最远角点离圆边仍有约 19px 余量，是否避开实际硬件触摸死区仍须真机确认。

- 字母分 2 页，保留 QWERTY 顺序，`1/2>` 表示当前页，点按循环翻页。
- `Aa`／`AA` 切大小写，字母页位置保持；数字／符号状态下点此键回字母。
- 每页右下固定 `DEL` 退格，其左侧字符类型键按 `123` → `#+=` → `ABC` 循环，分别进入数字、符号、字母。
- 数字共 1 页，符号共 3 页；加上大小写及独立空格键，可输入全部 95 个可打印 ASCII 字符，包含引号、反斜杠和空格。
- 底部依次是大小写、翻页、空格、连接。英文连接键用 `Join`，避免长词挤出小键；中文仍显示“连接”。
- 右上“显示／隐藏”切换密码可见性，默认隐藏。密码框与键盘分离，翻页、换字符类型、切大小写均不清空密码或重置输入位置。
