## 验证边界

历史 output/rc8-build.log 与 rc7 发布包属于当时版本。output/build-110.log 记录了 `idf.py: No such file or directory`，不能把版本号改为 1.1.0 视为已经构建成功。本轮环境检查确认 ESP-IDF 5.5.3 可调用；node/npm 检测有警告，本轮不生成字体。

本轮只执行路径、Markdown 本地链接、Python 语法、键盘字符和布局、现有字体覆盖及文案宽度检查。主机 C 回归与实际固件编译没有运行，当前完整功能验收未完成。
