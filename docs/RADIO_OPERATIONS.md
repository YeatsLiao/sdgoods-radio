适用：1.1.0-rc7（2026-10-30）。广播标签替换大字编辑风，像素唱片追加为第 11 套，八套角色／场景有常驻动效，默认中文。本版已编译、主机回归、打包并烧录到设备；物理触控手感与持续音频仍待真机长期验收。

已发布 RC6 的台名、频率和素材修订记录见 [RADIO_STATION_IDENTITY.md](RADIO_STATION_IDENTITY.md)。当前 11 套改动、构建身份与验证范围见 [RADIO_VISUAL_TUNING.md](RADIO_VISUAL_TUNING.md) 和 [RADIO_V3_RC7.md](RADIO_V3_RC7.md)。

顺序为：广播标签、点阵电波、像素主播、声波极简、猫咪 DJ、太空电波、海边落日、雨夜便利店、掌机音乐盒、像素花园、像素唱片。旧 `editorial` 设置自动对应广播标签，其余旧 ID 与顺序保持不变。

## 主屏

- **向左滑**：下一套风格；**向右滑**：上一套风格。11 套首尾循环，松手后切换并保存，下次启动恢复。
- 手势从背景／角色／文字区域起手；从按钮上起手不会切肤。使用 LVGL 原生手势识别，轻点空白不暂停，斜向／缓慢移动是否达到手势阈值仍取决于触摸设备输入。
- **顶部下滑**：打开平台控制中心。音量、亮度、电量、设置等沿用平台；第 5 键随设备模式显示 Power 或 Exit。
- **主屏上滑**：打开电台列表。从底部列表图标起手上滑也能打开。
- **左侧上一台／右侧下一台**：切相邻电台，首尾循环；与风格切换分开。
- **中间播放键**：暂停／恢复。连接失败或定时停止后点按会重试当前台；即使刷新目录后台的下标变了，也按缓存 URL 重试原台，不擅自切到第一台。
- **底部列表图标**：打开选台页。主屏没有额外的顶部设置／选台按钮栏，恢复参考图的中心构图。
- 不添加双击、长按或画圈的隐藏动作；不把它们作为必须学会的入口。

## 选台与设置

- 选台页每页 3 条，**左滑下一页、右滑上一页**；从电台行上滑动不会误点播放。下方箭头也可翻页，最多 64 台可达。
- **列表再次上滑**：退出列表回播放主屏，不退出应用，也不停止声音。点电台则播放并返回主屏。
- 页头统一为左侧返回、居中标题、右侧操作，位置避开系统顶部下滑区域。列表右上「设置」进入设置；列表左上返回主屏，设置左上返回列表，密码页左上返回 Wi-Fi 列表。
- 设置里保留 Wi-Fi、城市、外观、定时和刷新电台。二级页顶部下滑也接入平台控制中心。
- 「外观」页的左右**按钮**只是预览；「应用」才切换并保存；「返回」取消。主屏左右滑则是立即切换，两者语义不同。
- 列表、设置、外观和控制中心打开时，主屏切肤手势被隔离；操作页内按钮不会顺带切肤。
- 城市切换和目录刷新只重拉可选电台，不主动停止当前播放或重配 Wi-Fi。新列表加载好后由用户选台；手动暂停意图保持。城市保存失败保留旧选择并提示。

## 控制中心

- 底部向上滑：关闭控制中心，回到先前应用页面。
- 从左边缘向右滑：按平台规则返回控制中心上一级或关闭浮层，不切电台皮肤。
- 控制中心打开后，电台继续播放；此前已暂停的电台保持暂停。关闭控制中心不会自动恢复一个由用户暂停的电台。
- 控制中心切语言时，电台等待浮层关闭后再重建布局，避免销毁仍在使用的系统浮层。
- 电源键行为仍由平台接管，没有由电台重新绑定。

## 状态与失败

- 仅真实播放时点亮红色标记并显示 LIVE；连接、缓冲、暂停和错误显示相应文字。
- 有可靠 FM 身份时显示频率；没有频率的网络台不编造 MHz。点阵位显示目录编号并标注「网络频道」，无编号时显示 `WEB`；广播标签的下半区单行显示 `FM 105.4`／`CH 03`，无编号时显示「网络电台」。编号随目录刷新变化，不是 FM 频率。
- 皮肤切换不停止或重启播放器，不改变当前台、定时、城市或收藏配置；保存失败恢复旧皮肤并提示重试。
- 定时按当前设定停止声音，之后不因换肤或关闭控制中心自动出声。它不是设备关机或屏幕熄灭。
- 旧收藏数据保留，本版尚无新的收藏管理入口，陪伴时钟也未加入。原七套角色／场景与新增像素唱片均保持轻量动效：暂停、缓冲、连接失败时继续动，进入列表、设置、配网或控制中心后冻结，返回后接着动。像素主播另有播放／暂停表情；旋转或动效不代表正在输出音频，声音状态仍以播放键和状态文字为准。

## UI 对齐与验证

- 恢复顶部居中时间与 LIVE、较大的角色／频率／声波、底部三枚播放图标与独立列表图标。
- 广播标签使用奶油底与珊瑚色平面标签，台名和频率上下分区；像素唱片使用墨绿底、像素唱片与简化唱臂。广播标签、点阵、声波和初始像素主播保留无圆底的主播放键，其他像素／唱片风格沿用圆底主键。
- 主屏按用户确认图使用圆形可见区域，不再强行把全部控件压进 240×240 矩形。时间和 LIVE 分别上移到 y=28、52，角色区已放大；标签、唱片与底部列表键均需满足圆形弦宽，实际屏幕仍待真机检查。
- 台名、频率和状态仍是动态内容。广播标签改用 32px 单行品牌短名，长台名滚动，不再把汉字切成巨大的两行或重复全称；其他样式继续使用短名与长文滚动，列表保留完整名称。角色完整缩入透明画布，动画留出边距。
- 主机回归源码已扩展为 132 次视图重建、八套共 480 帧动画、新唱片预览与持久化、11 套首尾循环，并保留列表手势、64 台可达、配网与城市切换用例。本轮未编译或运行，只通过字体、文案宽度和几何静态核对。
- 主机注入手势事件验证的是事件路由与状态变化，不代表物理触摸阈值、系统控制中心手势或设备音频已实测。
