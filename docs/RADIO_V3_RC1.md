# 十皮肤电台 1.1.0-rc1 交付记录

日期：2026-10-30。状态：可供远端烧录的候选版，**未做真机验证**。用户明确选择聊天下载，不发布平台。

## 已实现

- 十套已确认风格共用播放器、目录和设置：编辑、点阵、像素主播、声波、猫咪、太空、海边、雨夜、掌机、水豚。
- 设置 → 外观：左右预览，应用后保存，返回取消；无法保存时恢复原皮肤并提示。
- 皮肤保存为稳定 ID，兼容旧纸张／夜色偏好；无记录默认点阵。切换不发出播放器停止／重新播放命令，用户暂停意图保持。
- 7 套像素／场景美术来自内置 ImageGen 生成的无文字图集；转换为 176×104、16 色索引图。加上像素主播暂停表情共 8 张，原始图像数据合计 73,728 字节，全部内嵌，不依赖 appdata 或额外下载。
- 真实台名、频率、时钟、播放状态与按键动态绘制；声波取真实音频电平。有频率才显示 FM，无频率显示网络电台。
- 清晰的设置、选台和三枚播放按钮；移除点击空白暂停、持续拖台及底部上滑开列表。平台控制中心继续由外壳管理。
- 电台列表每页 3 条，最多 64 台均可分页选择，初始定位当前台附近；减少同时创建的 UI 对象。
- 播放失败保留当前台，点击播放重试；不再静默连续跳到别的台。定时停止后维持暂停意图。
- 移除应用内串口临时导航／诊断键；平台 `?` 能力查询与 `s` 截图不变。

## 与后续计划的关系

当前完成十套静态皮肤的候选交付；台名采用现有网络字体，编辑风通过单字缩放重用字体数据。极长名称会省略，选台列表中可识别完整台名的能力仍受行宽限制。

连续场景动画、水平滑动换台、陪伴时钟和收藏稳定标识迁移尚未实现。旧收藏位图数据保持不变，第一版没有新增收藏管理界面。真实设备测试后再决定动画与手势方案，不能把风格概念图当作逐像素还原验收图。

## 复现

在已激活的 ESP-IDF 环境中运行 `idf.py build`，不删除构建目录。环境路径及激活方式见 `RADIO_V3_FIRMWARE_PLAN.md`。

素材转换（Pillow 仅重生成时需要）：

```powershell
python tools/prepare_radio_assets.py --atlas main/assets/radio/atlas-source.png
python tools/add_license_headers.py --apply --files main/apps/ui_radio_assets.c main/apps/ui_radio_assets.h
```

主机离线检查（本机原生 GCC 与 Pillow）：

```powershell
python tools/test_radio_host.py
```

输出在 `output/radio-host/`，不入库。图集源图与转换清单位于 `main/assets/radio/`；十套设计档案位于 `docs/design/radio-v3/`。

本次顺带修复了许可脚本在 Windows 下未排除 fonts／patches 的路径分隔符问题，并添加 `--files`，以免运行许可脚本时改动上游声明或无关文件。实际未改平台分区、驱动缓冲、LCD 序列、音频时序或 LVGL 补丁。
