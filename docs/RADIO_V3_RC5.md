# Radio 1.1.0-rc5 中文、交互与联网修订

2026-10-30。本轮只读取 COM6 原有固件的截图和日志，未复位、未烧录。保留十套风格与七套动画，应用打开时通过公开语言 API 设置为中文；中英文字符串及英文兼容性检查仍保留。

## 页面和手势

- 去掉突兀的 X。页头左侧为统一返回箭头，中间为标题，右侧放设置／重扫等操作。
- 返回键 y=74 起，避开平台 y<70 的控制中心捕获区；列表翻页改为单箭头，底部有上滑提示横条。
- 主屏上滑打开电台列表，列表左滑／右滑翻页，再上滑退出列表回主屏。列表最多 64 台，点台播放。
- 主屏背景左右滑仍换风格；列表内滑动不会切风格，也不会顺带触发电台点击。
- 设置返回列表、密码页返回 Wi-Fi 列表、外观取消返回设置；返回操作和页面销毁走异步，重复打开不会留下未追踪的旧页面。

## 中文配网页

先前给出的英文截图来自英文测试模式，不能代表用户要求的中文预览。新版默认中文并单独导出中文页面。

密码页分成标题、网络名称、输入框、键盘四块：名称 y=123..140，输入框 y=146..177，键盘从 y=190 开始。键盘按圆屏弦宽逐行计算，使用 30px 行高。已做矩形边界断言并目视检查，文字不再撞分隔线或密码框。

中文截图在 `docs/design/radio-v3/rc5/`。列表中的测试电台和 Test WiFi 是主机测试数据，设备使用真实电台名和 SSID。

## 网络与城市修订

- 联网状态核对路由器关联和有效 IPv4，避免单靠漏掉／过期的事件变量误报。设置页打开后持续更新状态。
- 连接提交处于等待期间时不把旧连接当成新连接成功；定时器复用，重复提交不覆盖等待中的请求。凭据保存和任务提交失败返回给界面。
- 信号丢失后使用延迟重试，不再重试几次就停掉 Wi-Fi、强制切为配网热点。明确手动重新配网时才执行网络配置切换。
- 配网等待标志改为页面清理后设置。等待页不再被扫描结果覆盖；连接成功后正常收尾，密码页返回也不会留下隐藏但仍被判定为打开的页面。
- 手机配置页读完整个请求体再处理；空密码只允许复用同名 SSID 的旧密码。
- 切城市保留当前台名、URL、播放／暂停状态，不调用停止播放或 Wi-Fi 重配。手动城市跳过多余定位请求；连续换城市通过代际标识丢弃旧结果。
- 城市保存失败保持旧城市。保存错误提示不再被 LIVE 标签覆盖。
- 目录失败的兜底集合改称“预设电台”，不再把在线网络电台标为“离线精选”。Wi-Fi 恢复后刷新目录，保留暂停意图。

## 验证及边界

真实 LVGL 主机检查通过：120 次视图重建、420 帧动画、指针按在底部图标和电台行上滑动、64 台分页、设置状态变化、城市切换不停止音频、城市保存失败和连续城市任务过期处理、密码页返回与配网成功收尾。

真实 `wifi_prov.c` 与 `wifi_prov_status.c` 使用 SDK 替身做回归：启动幂等、已有连接接管、缺 IP／残留 IP／未关联、12 次连续断线不切热点、重连恢复、重复请求、持久化与定时器失败。播放器既有主机回归继续通过。

中文子集和文本宽度检查通过。真实固件编译和应用包校验结果随下载包记录。主机测试不能替代实际 AP、DHCP、无线信号、物理触摸和连续音频验收；本轮遵照用户要求不烧录。

此前建议的 256KB 自适应稳播缓冲和源评分仍属后续计划，本版没有把它们列为已实现。
